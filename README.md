# 📚 Sobre o Projeto

Este projeto tem como objetivo desenvolver um jogo interativo educativo utilizando Figma e algumas linguagens de programação.

A iniciativa feita por um projeto social realizado em parceria com a Secretaria da Educação do Município de Brusque, com o objetivo de criar um quiz educativo e interativo para as crianças de forma divertida e acessível.

---

# 🎯 Objetivos

✔️ Desenvolver um jogo educativo  
✔️ Aplicar conceitos de programação  
✔️ Trabalhar em equipe
