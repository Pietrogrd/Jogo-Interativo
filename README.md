# 📚 Sobre o Projeto

Este projeto tem como objetivo desenvolver um jogo interativo educativo utilizando tecnologias web, promovendo aprendizado, criatividade e inclusão digital.

A iniciativa faz parte de um projeto social realizado em parceria com a Secretaria da Educação, incentivando o uso da tecnologia como ferramenta de ensino.

---

# 🎯 Objetivos

✔️ Desenvolver um jogo educativo e interativo  
✔️ Aplicar conceitos de programação web  
✔️ Trabalhar colaboração em equipe  
✔️ Utilizar Git e GitHub para versionamento  
✔️ Contribuir com o projeto social educacional
