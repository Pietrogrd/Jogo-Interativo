# 🎮 Jogo Interativo

## 📚 Sobre o Projeto
Projeto desenvolvido em parceria com a Secretaria da Educação, com o objetivo de criar um quiz educativo interativo.

---

## 🎯 Objetivo
- Desenvolver um jogo educativo e interativo.
- Aplicar conceitos de programação.
- Trabalhar em equipe.
